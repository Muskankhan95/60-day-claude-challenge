Welcome to my **60 Days of Claude AI Challenge!**

This repository documents my journey of learning, experimenting, and building with **Claude AI** every single day.

Instead of simply consuming AI content, I'm focusing on **hands-on practice**, **real-world applications**, and **creative problem solving**.

Each day includes something new:
