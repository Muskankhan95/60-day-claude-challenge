# Day 2 - What Is Prompt Engineering

**Date:** 27 July 2026

## Objective

Learn how prompt engineering improves the quality of AI responses by comparing a simple prompt with a well-structured prompt.

---

## What I Worked On

Today I completed the Prompt Engineering challenge using Claude AI.

I:
- Opened Claude and started a new chat.
- Entered a simple (lazy) prompt and generated the response.
- Saved the output.
- Started a new chat.
- Used an engineered prompt.
- Compared both outputs.
- Observed the differences in quality, structure, and clarity.

---

## Lazy Prompt

```text
Create an image explaining Prompt Engineering.
```

---

## Engineered Prompt

```text
Act as an expert AI educator and infographic designer.

Create a visually appealing educational infographic explaining Prompt Engineering.

Include:
- A simple definition
- Why prompt engineering is important
- The anatomy of a good prompt
- Weak vs. strong prompt examples
- Best practices
- Common mistakes
- A summary

Use a clean, beginner-friendly layout with headings and icons.
```

---

## Key Learnings

- Prompt engineering helps AI generate more accurate and useful responses.
- Giving clear instructions leads to better results.
- Providing context and specifying the desired output format improves quality.
- Well-designed prompts reduce ambiguity and make responses more structured.

---

## Comparison

### Lazy Prompt Output
- Basic explanation
- Less detail
- Simple structure

### Engineered Prompt Output
- Detailed and organized
- Better explanations
- Clear examples
- More professional presentation

---

## Conclusion

Today's activity showed me that the quality of an AI's response depends heavily on how the prompt is written. By providing clear instructions, context, and formatting requirements, I was able to get a much more useful and informative response.
